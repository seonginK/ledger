이 페이지는

엑셀이 공식 장부(원본)이고, 이 페이지는 핸드폰에서 적고 확인하는 보조 장부예요. 둘은 자동으로 연결되지 않아서, 핸드폰에서 적은 건 엑셀로 옮기기, 엑셀에서 적은 건 엑셀에서 가져오기로 맞춰요.

컴퓨터와 핸드폰에서 같은 주소로 열고 같은 구글 계정으로 로그인하면 같은 내용이 보여요.

매일 적기

  1. 아래 + 지출 적기(또는 + 수입 적기)를 눌러요.
  2. 날짜·금액·항목·적요를 적고, 지출구분에서 돈이 나간 통장·현금을 골라요. 개인카드로 썼으면 쓴 사람 이름을 골라요.
  3. 목록에 없는 항목이나 사람은 칸 아래 "+ … 추가"로 바로 넣어요. 엑셀 목록에도 같은 이름을 넣어야 해서 "엑셀에서 고칠 것"에 적어 둬요.
  4. 저장한 새 내역은 눌러서 고치거나 지울 수 있어요. 엑셀에 이미 있는 내역(엑셀 ○행)은 엑셀에서 고쳐요.

개인카드로 썼을 때

  1. 지출구분에서 쓴 사람 이름을 고르면 빨간 미입금이 붙어요. 쓴 날 바로 지출로 잡혀요.
  2. 법인통장에서 그 사람에게 입금해 주면, 그 내역의 입금 처리에서 날짜만 넣어요 → 입금완료.
  3. 엑셀에 이미 있는 줄이면 엑셀 입금일 칸에도 적어야 해서 "엑셀에서 고칠 것"에 나와요. 엑셀에 적고 고쳤어요를 눌러요.
  4. "개인카드 입금" 줄은 따로 적지 않아요(두 번 빠져요).

핸드폰 → 엑셀로 옮기기

복사·붙여넣기는 같은 기기 안에서만 돼요. 엑셀이 컴퓨터에 있으면 이 페이지도 컴퓨터에서 열어서 하세요.

  1. 입력·내역 탭 ① 일~지출 복사 → 엑셀 그 달 탭 빈 줄의 일 칸(C열)에 붙여넣기
  2. ② 지출구분·입금일 복사 → 같은 줄의 지출구분 칸(I열)에 붙여넣기
  3. 엑셀에 잘 들어갔는지 본 뒤 ③ 엑셀에 옮겼어요 → 다음부터 다시 복사되지 않아요.
  4. ③을 잘못 눌렀으면 바로 아래 "방금 표시 되돌리기"를 눌러요.

엑셀 → 핸드폰 가져오기

  1. 페이지 맨 위에서 맞출 달을 골라요.
  2. 엑셀 그 달 탭에서 A열(No.)~J열(입금일), 10행부터 마지막 거래 줄까지 선택해 복사해요.
  3. "엑셀에서 가져오기" 칸에 붙여 넣고 미리보기 → 수입·지출 합계가 엑셀 "이번 달 합계" 줄과 같은지 확인 → 맞추기.
  4. 핸드폰에만 있는 내역(아직 안 옮긴 것)은 그대로 남아요. 잘못 맞췄으면 "마지막 가져오기 되돌리기"를 눌러요.

엑셀과 시재가 맞는지 확인하기

먼저 엑셀에서 가져오기로 그 달을 맞추고, 핸드폰에만 있는 내역(옮길 내역)이 없는 상태에서 비교하세요.

핸드폰엑셀에서 보는 곳
잔여예산 (가지급 전)월 탭 맨 위 잔여예산
현재 시재 (가지급 후)맨 위 오른쪽 분홍 현재 시재 (= 맨 아래 가지급 합계 줄의 가지급 후 잔액)
가지급 합계맨 아래 가지급 현황의 가지급 합계

통장별 통장 잔액통장별 잔액 표 오른쪽 분홍 통장 잔액(은행)
현금 계산 탭맨 아래 오른쪽 현금 시재 확인 (같은 계산)

실제 돈과 맞추기

  1. 통장: 확인 탭 "통장별 잔액"의 통장 잔액을 각 은행 앱 잔고와 비교해요.
  2. 현금: 현금 계산 탭에 권종별 수량을 넣으면 "✔ 장부와 일치" 또는 "⚠ ○원 부족/많음"이 나와요.
  3. 개인카드: 사람별 미입금이 실제로 아직 안 갚은 돈과 같은지 봐요.

숫자가 다를 때 확인할 것

  • 핸드폰에만 있는 내역이 있나요? (입력·내역 탭 "옮길 내역 ○건")
  • 엑셀에서 적은 내역을 가져왔나요? (그 달 엑셀에서 가져오기)
  • 가지급이 엑셀과 같나요? 다르면 확인 탭 가지급 고치기로 엑셀 맨 아래 가지급 현황과 같게 맞춰요.
  • 지출구분이 빈 내역이 있나요? 있으면 통장별 잔액에서 빠져요(확인 탭 빨간 안내). 엑셀에서 채우고 다시 가져오세요.
  • 엑셀 월 탭 오른쪽 위 점검 칸이 "⚠ 확인 필요"인가요? 엑셀 쪽 누락부터 고쳐요.

알아두면 좋은 점

  • 입력한 내용은 바로 저장돼요(인터넷 연결 필요). 따로 저장 버튼은 없어요(내역 저장 버튼 제외).
  • 앱 주소를 다른 사람이 알아도, 허락한 구글 계정이 아니면 장부를 열 수 없어요.
  • 매달 결재받은 뒤에는 엑셀 파일 사본을 하나 저장해 두면 안전해요.

핸드폰 홈 화면에 앱으로 두기

  • 아이폰(사파리): 아래 가운데 공유 버튼 → 홈 화면에 추가
  • 갤럭시(크롬·삼성 인터넷): 오른쪽 위(아래) 메뉴 ⋮ → 홈 화면에 추가 또는 앱 설치
  • 홈 화면 아이콘으로 처음 열 때 한 번 더 구글 로그인을 할 수 있어요.

백업

장부 전체(설정·내역·현금 수량)를 파일 하나로 저장해요. 매달 결재가 끝나면 한 번씩 저장해 두세요.
